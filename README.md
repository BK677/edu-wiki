🤖 EduWiki AI Assistant

EduWiki AI Assistant, kullanıcıların Google Gemini API aracılığıyla yapay zekâ destekli bir sohbet deneyimi yaşamasını sağlayan bağımsız bir AI asistan projesidir.

Proje; eğitim, araştırma, kodlama, genel bilgi ve günlük öğrenme süreçlerinde kullanıcılara yardımcı olmak amacıyla geliştirilmiştir.

«Önemli: Bu proje Google Gemini API kullanır. AI özelliklerini kullanabilmek için kullanıcının kendi Gemini API anahtarını sağlaması gerekir.»

🔑 Gemini API Anahtarı Gereksinimi

AI asistanını kullanmak için kullanıcının kendi Gemini API anahtarını sağlaması gerekir.

Örnek:

Gemini API Key
       ↓
EduWiki AI Assistant
       ↓
Google Gemini API
       ↓
AI yanıtı

Proje geliştiricisinin ortak bir Gemini API anahtarını kullanıcılara dağıtması amaçlanmamaktadır.

Neden kullanıcı kendi API anahtarını kullanıyor?

Bu sistem sayesinde:

- Kullanıcı kendi API kullanımını kontrol edebilir.
- Proje geliştiricisinin tek bir API anahtarını bütün kullanıcılar tüketmez.
- API kullanımından doğabilecek limitler kullanıcı hesabına bağlı olur.
- Projenin ortak bir API anahtarına bağımlılığı azalır.

⚠️ API Anahtarı Hakkında Önemli Uyarı

API anahtarınızı başka kişilerle paylaşmayın.

API anahtarları kişisel erişim bilgileri gibi korunmalıdır.

API anahtarınızı:

- GitHub'a yüklemeyin.
- Herkese açık JavaScript dosyalarına yazmayın.
- Ekran görüntülerinde paylaşmayın.
- Başka kişilere göndermeyin.
- Güvenmediğiniz web sitelerine vermeyin.

Bir API anahtarının açığa çıktığını düşünüyorsanız Google AI Studio / Google Cloud üzerinden gerekli güvenlik işlemlerini yapmanız önerilir.
